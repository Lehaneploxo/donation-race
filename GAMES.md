# Список игр проекта

Полный реестр всех игр, чтобы не забывать про те, что временно убраны со стартовой страницы (`client/launcher.html`).

## Активные (кнопки видны на launcher.html)

| Игра | Роут | Файл | Заметки |
|---|---|---|---|
| 🥊 Boxing Arena | `/boxing` | `client/boxing_arena.html` | Battle royale боксёров, лайки/донаты, чат-команда "rating" |
| 📊 Boxing Arena — база данных | `/boxing-db` | `client/boxing_db.html` | |
| 🥊 Boxing Arena (EN) | `/boxing-en` | `client/boxing_arena_en.html` | Английская версия, отдельный топ-лист |
| 📊 Boxing Arena (EN) — база данных | `/boxing-db-en` | `client/boxing_db_en.html` | |
| 🥋 Street Fighters | `/streetfighter` | `client/streetfighter_arena.html` | Текущая активная игра, чат-команда "rating" |
| 📊 Street Fighters — база данных | `/streetfighter-db` | `client/streetfighter_db.html` | |
| 🎣 Рыбалка | `/fishing` | `client/fishing.html` | 8-я игра (10.08.2026). Фон — зацикленное видео причала/моря (`client/img/fishing_bg_video.mp4`). Рейтинг = сумма рыбок: 1 монета/100 лайков = 1 рыбка, размер подарка определяет только вид рыбы (мелкая/щука 100+/акула 1000+), не влияет на счёт. "ТОП ЗА СЕГОДНЯ" сбрасывается в полночь по Киеву, всего рыбок — вечный счётчик. Чат-команда "rating" |
| 📊 Рыбалка — база данных | `/fishing-db` | `client/fishing_db.html` | |
| 🏰 Fantasy Arena | `/fantasyarena` | `client/fantasy_arena.html` | 9-я игра (18.08.2026). Крауд-арена 1-в-1 логика Street Fighter: лайки/донаты растят Энергию/Силу бойца-зрителя, уровень (1-50) от lifetime-очков, ежедневный сброс дневного топа/короны в полночь по Киеву. 4 героя (Рыцарь/Самурай/Маг/Охотница) × 7 цветов каждый (`scripts/recolor_fantasy_arena.js`), чат-команда "hero1"-"hero4" закрепляет героя навсегда. 8 фонов (ansimuz), автосмена каждые 5 мин. Чат-команда "rating" |
| 📊 Fantasy Arena — база данных | `/fantasyarena-db` | `client/fantasy_arena_db.html` | |
| 🏛️ Цивилизация | `/civilization` | `client/civilization.html` | Перемещена в самый низ списка (02.08.2026) — редко используется, но актуальна |
| 🤝 Взаимки | `/vzaimki` | `client/vzaimki.html` | НЕ игра (24.08.2026) — интерактивный оверлей поверх TikTok LIVE: считывает донаты/лайки/подписки в реальном времени, показывает TOP 3/TOP 10 по coins/взаимкам/лайкам, голосовая ведущая (browser TTS) призывает подписываться друг на друга. Все данные только в памяти текущего эфира (без БД), сбрасываются при каждом новом LIVE. Формат экрана 600×1000 — задуман как прозрачный оверлей поверх видео эфира, не отдельная игра. Отладка: `?debug=1` — панель с ручными тестовыми событиями (TEST GIFT/FOLLOW/LIKE/TOP CHANGE, нагрузочный тест) |
| 💗 Тамагочи | `/tamagotchi` | `client/tamagotchi.html` | НЕ игра (26.08.2026) — виртуальная девушка в комнате, живёт непрерывно от подарков TikTok: голод (растёт сама, еда закрывает, лишняя еда после сытости идёт в вес), вес (процедурный SVG-морфинг тела, плавный, без готовых ассетов), настроение, одежда по слотам (верх/низ/платье/обувь/аксессуар). Состояние персистится в БД (`game_state_snapshots`, game='tamagotchi'), без сброса между эфирами. Маппинг подарок→действие — `server/tamagotchiConfig.js`, правится без изменения логики. Отладка: `?debug=1` — панель ручных тестовых действий |
| ⚔️ Avatar War | `/avatarwar` | `client/avatar_war.html` | 10-я игра (26.08.2026, вдохновлено Territory War с keepmy.live). Захват территории по клеткам: поле 10×13, команда 1 стартует слева, команда 2 справа. Цифра "1"/"2" в чате разово (залипающе) выбирает команду зрителя. Донат = персональный юнит-аватарка донатера (реальное фото профиля TikTok на canvas, не спрайт) — красит клетки под цвет команды, продвигаясь к вражескому краю поля (растёт скорость от суммы донатов). Лайки разгоняют скорость покраски всей команды (каждые 10 лайков = +12%, потолок ×3). Победа — 70% поля закрашено одним цветом, раунд перезапускается, команды/донаты/территория сбрасываются, счёт раундов остаётся. Уровень 1-100 общий со шкалой Boxing/Street Fighter/Fantasy Arena (небольшой бонус к скорости), ежедневный сброс рейтинга ("командир дня") в полночь по Киеву. Не путать со скрытой `war.html` (бой юнитов и базы с HP, другая механика). Отладка: `?debug=1` |
